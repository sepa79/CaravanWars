# Codex Reboot Notes

Key reboot changes:

1. Maps are not truth.
2. The graph is truth.
3. Roads are waypoint chains.
4. Parchment maps are atmospheric overlays.
5. Player navigation uses landmarks, directions, travel memory, and local knowledge.
6. The player may leave the graph.
7. A hidden coordinate system exists underneath.
8. Runtime graph expansion is supported.
9. The large world map UI is removed.
10. Region parchment maps replace the global world map.
11. Server-authoritative simulation is the base path for singleplayer and multiplayer.
12. AI and future human-controlled roles use the same command interface as the player.
13. Singleplayer MUD-like simulation is the primary experience; multiplayer is optional.
14. Historical hierarchy and social brutality are simulation inputs, not decorative lore.

Target feeling:
- Darklands,
- Arcadia / MUD navigation,
- post-Roman early medieval Europe,
- caravan, trade, travel, and conflict simulation.
- a socially alien world where rank, fear, violence, patronage, and rumor matter.
- Sapkowski rather than high-myth heroic fantasy: good intentions are not plot armor.
